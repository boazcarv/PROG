# Agenda de contatos

Projeto desenvolvido com Angular para cadastrar e consultar contatos.

## Servidor de desenvolvimento

Para iniciar o projeto, execute:

```bash
ng serve
```

Depois, acesse `http://localhost:4200/` no navegador. A página será atualizada automaticamente ao salvar uma alteração.

## Criar componentes

Para criar um novo componente, execute:

```bash
ng generate component nome-do-componente
```

Para consultar todos os comandos disponíveis:

```bash
ng generate --help
```

## Compilação

Para compilar o projeto:

```bash
ng build
```

Os arquivos gerados ficarão na pasta `dist/`.

## Testes

Para executar os testes:

```bash
ng test
```

Para mais informações, consulte a [documentação do Angular CLI](https://angular.dev/tools/cli).
